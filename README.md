# Blueberry Cheesecake Recipe Page

A recipe page for Blueberry Cheesecake built using pure HTML.

## About the Project
This is one of my first HTML projects built as part of my web development learning journey.
The page covers a complete recipe — ingredients, step by step instructions, and a video reference.

## What I Used
- Semantic HTML elements — article, section, figure, figcaption
- Nested ordered and unordered lists
- iframe to embed a YouTube video reference
- em and strong for text emphasis
